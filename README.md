# NL ADORN — Vercel-ready static website

A responsive, single-page accessories storefront made with HTML, CSS, and vanilla JavaScript.

## Deploy to Vercel
1. Extract this ZIP.
2. Create a GitHub repository and upload `index.html`, `style.css`, `script.js`, and `vercel.json` to the repository root.
3. Visit https://vercel.com and choose **Add New → Project**.
4. Import the GitHub repository.
5. Choose **Other** for Framework Preset. No build command is required; leave the output directory blank.
6. Click **Deploy**.

## Preview locally
Open `index.html` in your browser. The product photography and Google Fonts use external URLs and require internet access.

## Customize before launch
- Replace sample product names, prices, and photos with your real products.
- The cart, search, and newsletter are front-end demo interactions only. They do not process payments, store orders, or submit emails to a mailing list.
- Update contact and social links when ready.
